## 01 / About Me

I'm a **Frontend Developer** focused on building responsive, intuitive, and visually polished web applications.

I enjoy transforming ideas and Figma designs into functional digital products, writing maintainable code, and creating interfaces that balance aesthetics with usability.

- Building modern web applications using Angular, React and TypeScript.
- Developing responsive interfaces with clean and reusable components.
- Integrating REST APIs and working with backend services.
- Exploring frontend architecture, performance optimization and scalable UI patterns.
- Working across traditional development and no-code platforms.

**Currently exploring:** Advanced React, modern Angular architecture, TypeScript patterns and frontend performance.

**Interested in:** Frontend engineering, product development, open-source collaboration and creative web experiences.
